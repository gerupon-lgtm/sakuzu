# サクズ（sakuzu）

二円交点・距離と方向（直角の折れ点）で点を決め、寸法の入った図面を作るPWA。SIKUMI LAB。

- 状態: SZ-0.4.0（MVP＋周囲の記載・引照点＋操作の仕上げ）
  - 作図: 基準点、距離と方向、二円交点（候補の選択・許容値）、手順の修正と追従、削除と元に戻す、閉合とずれ
  - 図面要素: 線、部屋（面積・一覧表）、道路（幅）、寸法（計算値の表記）、文字、北の記号、計測、回転（見た目だけ）
  - 周囲の記載: 四角・直線・寸法線（自由な位置）、縦書きの文字、斜線の塗り、引き出し線、引照点（一覧表つき）
  - 概算面積の表示、図面のプレビューと印刷（A4・A3、縮尺の自動選択、表題欄、作成日）
  - 操作: 設定画面（許容値・表示単位・作成者名）、基準点の追加と座標の修正、手順の並べ替え、重なった点の一覧選択、長押しの拡大鏡、寸法・面積の数値の移動と矢印での微調整
  - PWA（オフライン）、図面の一覧と自動保存、作業ファイルの書き出し・読み込み
- 予定: 取り込み版（SIMA・CSV・DXF、F-022〜F-027）、三斜法（F-028）
- 開発: `npx serve .` で開く。テストは `TZ=UTC node --test tests/*.test.mjs`、版の確認は `node scripts/check-version.mjs`
- 実機での確認: docs/manual-check.md
- 設計: docs/（要件定義書・実装ガイド・処理設計・画面設計・タスク）
