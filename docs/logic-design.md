幾何の計算そのもの（二円交点、距離と方向、面積、丸め、縮尺の選び方）は、共通モジュールを使う。ここでは、サクズ独自の「手順の記録と再計算」「閉合」「部屋」「道路」「寸法」を定める。

### SZ-L01 手順の種類と計算

| 種類 | 保存する値 | 計算 | エラー |
|---|---|---|---|
| `base` 基準点 | x, y（初期値は 0, 0） | そのまま | なし |
| `polar` 距離と方向 | from（点ID）、ref（基準の辺: [点ID, 点ID] または null）、turn（`"L"` / `"R"` / `"S"`）、angleDeg（0〜180）、d（m） | ref の向き（ref[0]→ref[1]）に、左なら +θ、右なら −θ を足した向きへ、from から d 進む。ref が null（前の辺がない）なら、向きは x軸の正の向き（画面の右向き）から測る。直角の折れ点は turn = L/R、θ = 90 | `POLAR_BAD_DISTANCE`（d ≤ 0）、`POLAR_BAD_ANGLE`（範囲外） |
| `circles` 二円交点 | a、da、b、db（m）、side（`"L"` / `"R"`） | 共通モジュールの `circleIntersect(A, da, B, db, side, tol)`。tol は設定の許容値（初期値0.03m） | `CIRCLE_SAME_CENTER`、`CIRCLE_NO_INTERSECTION`（gap を表示） |

- 「距離と方向」の ref の初期値: from を終点とする直前の線の辺（from を作った polar 手順の from→to）。直前の辺がない、または from が二円交点で作られた点の場合は、利用者に基準の辺を選んでもらう（初期値は、最後に引いた線）。
- 角度0° は直進、180° は折り返し。
- 数値の入力: 長さは m で小数第3位まで（それより細かい桁は四捨五入）、角度は小数第2位まで。

**検証**
- base(0,0) → polar(d=5) → polar(R, 90°, 2.5) → polar(R, 90°, 5)
  - 点は (0,0)、(5,0)、(5,−2.5)、(0,−2.5) になる。
- polar(L, 45°, √2) で、(1,1) 方向の点ができる（誤差1e-9以内）。

### SZ-L02 二円交点の候補と、選んだ側

1. 入力が終わったら、`candidates()` で2つの候補を求め、図の上に両方を表示する。
2. 利用者がタップした候補の側（L/R）を `side` に保存して、手順を確定する。確定するまでは、手順の一覧に「候補を選んでください」と表示する。
3. 接する場合（gap ≤ tol）は候補が1つになる。そのまま確定し、警告として隙間（cm）を表示する。
4. 数値を直したときは、保存した `side` を使って計算し直す。

**検証**
- A(0,0)、B(4,0)、5m・3m で左を選ぶ → (4,3)。
- その後、da を 5.1 に直しても、左側（y > 0）の点のままになる。

### SZ-L03 再計算と、状態の伝わり方

- 手順は配列で持つ。各手順は、自分より前の手順の点だけを参照できる。
- 数値を直したら、その手順の位置 i から最後までを順に計算する（計算量は O(n)）。
- 各点の状態:
  - `ok`: 問題なく計算できた。
  - `warn`: 接する点として扱った。
  - `error`: この手順自体が計算できない。
  - `blocked`: 参照している点が `error` か `blocked` のため、計算できない。
- `error` と `blocked` の点は図に描かない。それらの点を使う線・部屋・寸法・道路も描かず、手順の一覧に印を付ける。
- 手順の並べ替え: 参照の制約（前の手順だけを参照する）を守る位置にだけ動かせる。

**検証**
- 二円交点の手順を `error` にすると、それに依存する3つの点が `blocked` になる。数値を直すと、すべて `ok` に戻る。
- 200点の図で、先頭の数値を直してから計算が終わるまで 10ms 以内（Node で計測する）。

### SZ-L04 依存関係・削除・元に戻す

- 依存関係: 手順・線・部屋・道路・寸法・文字が参照している点IDから、逆向きの対応表を作る。
- 削除:
  1. 削除する点に依存するものを、すべて集める（推移的に）。
  2. 「この点を削除すると、ほかに N 個の点と M 個の要素も削除されます」と確認する。
  3. 承認されたら、まとめて削除する。
- 元に戻す・やり直す: 操作のたびに、図面のデータの複製を履歴に積む（最大50件。古いものから捨てる）。アプリを閉じると、履歴は消える。
- 新しい操作をしたら、やり直しの履歴は捨てる。

**検証**
- 二円交点のもとにした点を削除すると、交点と、それを使った寸法も削除される。
- 元に戻すで、すべてが戻る。
- 51回操作すると、最も古い履歴が消える。

### SZ-L05 線と閉合・ずれ

- 線: 点IDの列と、閉じているかどうか（closed）を持つ。
- 「最終点」の指定:
  - **閉じる辺を測っていない場合**: 最後の点から最初の点へ線を引いて閉じる。ずれの判定はしない。
  - **閉じる辺を「距離と方向」で測った場合**: 計算で求めた到達点 E と、最初の点 S の差 v = E − S を「ずれ」とする。
    - |v| < 0.0005m のときは、「ずれなし」として閉じる。
    - それ以外は、ずれの距離（cm）と向き（矢印）を表示し、次のどちらかを選んでもらう。
      - **そのまま閉じる**: 図形の頂点は S を使う。到達点 E は確認用として手順の一覧に残し、図には描かない。図面の閉じる辺には、計算上の長さ |最後の点 − S| を表示する。
      - **測り直す箇所の目安を見る**: v の向きとの角度の差（向きは問わない）が20°以内の辺を強調表示する【想定】。
  - **閉じる辺の長さだけを測った場合**（角度なし）: 差 = 計算上の長さ − 測った長さ を表示する（向きは出さない）。選択肢は同じ。

**検証**
- 5m×2.5m の長方形で、最後の辺を 2.51m と入れると、ずれ 1cm で、向きは最後の辺と同じになる。
- 目安として、向きが平行な辺（2.5m の2辺）が強調表示される。

### SZ-L06 部屋と道路

**部屋**
- 点IDを順に選んで作る（3点以上）。名前を付ける。
- 面積: `area()` で計算し、`formatArea()` で小数第2位に四捨五入して表示する。
- 多角形が不正な場合は、`validatePolygon()` のエラーを表示する。
- 合計は、丸める前の値を足してから丸める。

**道路**
- 敷地の辺（隣り合う2点）、幅 w、名前を持つ。
- 反対側の線は、その辺を、敷地の外側（多角形の重心と反対の側）へ w だけ平行に移したもの。外側を判定できない場合は、利用者が向きを切り替えられる。
- 線は両端から1mずつ延ばす【想定】。幅の寸法を自動で付ける。

**検証**
- 3m×4m と 2m×4m の部屋が辺を共有している場合、12.00㎡、8.00㎡、合計20.00㎡ になる。
- 道路の反対側の線が、敷地の外側に描かれる。

### SZ-L07 寸法の自動生成

- `polar` で作った点と、その from を結ぶ線が描かれている場合は、その2点に自動で寸法を付ける（`auto: true`、手順IDを持つ）。
- 手順を削除すると、自動の寸法も一緒に消える。
- 二円交点の距離a・bは、作図用の補助線（破線。印刷しない）として表示する。
- 手動の寸法: 2点を選んで追加する。離れ（offset）は、ドラッグで調整する。
- 表示の単位は図面ごとに選ぶ（m は小数第2位、mm は整数）。

### SZ-L08 図面の縮尺と配置

- 描画範囲 = 用紙から、余白10mm、表題欄、部屋の一覧表の領域を除いた部分。
- 縮尺は、共通モジュールの `selectDrawingScale()` に、次の候補を渡して選ぶ: 1/20, 1/30, 1/50, 1/100, 1/150, 1/200, 1/250, 1/300, 1/500【想定】。
- 図面の向き: 作図した向きのまま描く（北の記号は、利用者が置いた向き）。

## エラーコードと文言（初期案）

| コード | 文言 | 回復方法 |
|---|---|---|
| CIRCLE_NO_INTERSECTION | 円が交わりません（あと◯cm足りません） | 距離を直す、または設定で許容値を変える |
| CIRCLE_SAME_CENTER | 2つの点が同じ位置です | 別の点を選ぶ |
| POLAR_BAD_DISTANCE | 距離は0より大きい値を入れてください | 入力し直す |
| POLY_SELF_INTERSECT | 線が交差しています | 部屋の点の順番を直す |
| FILE_WRONG_APP | このファイルはサクズのものではありません | 正しいファイルを選ぶ |
