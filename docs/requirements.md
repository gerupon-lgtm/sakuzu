## 2. はじめに（背景・目的）

- **背景**: 車庫証明の保管場所の図面や、保健所に出す店内の概要図を、ドローソフトやCADで、基準点からの二円交点を重ねて作ってきた。この方法には、次の手間がある。
  - 1点ごとに作図の手間がかかる。
  - 寸法を直すと、そこから先を描き直すことになる。
- **目的**: 点の求め方（二円交点、距離と方向、直角の折れ点）を手順として記録し、寸法の入った図面を、スマホとPCで素早く作り、素早く直せるようにする。
- **ざっくり地積との住み分け**: 数値・ベクターのデータ（手入力、SIMA・CSV・DXF）を扱うのがサクズ、画像（ラスター）から読み取るのがざっくり地積。
- **位置づけ**: 発案者が自分で使う。うまく動けば、ほかの人に無償で使ってもらってよい。作らなくても困ることはない。

## 3. スコープ

**対象**
- 車庫証明の配置図（保管場所の形、寸法、道路と道路の幅）
- 店内の概要図（部屋の配置、部屋の名前と面積）

**対象外・保留**

| 項目 | 理由 | 再検討の条件 |
|---|---|---|
| 車庫証明の所在図（周辺の地図） | 地図サービスで用意する前提にする（発案者合意） | — |
| 什器の配置、出入口（扉）の記号 | 後で考える（発案者回答） | 最初の版が安定したら |
| 壁の厚み | 線だけで表す（発案者合意） | 提出先から求められたら |
| 北を基準にした方位角の入力 | 閉じた使い方なので不要（発案者回答） | — |
| 2本の線の交点・垂線の足による点の作成 | 最初の4つの操作で足りるか、使ってから判断する | 使っていて必要になったら |
| DXFの出力 | ざっくり地積と共通モジュールで作る予定。その完成を待つ | 共通モジュールにDXFの出力ができたら |
| 拘束ソルバ（条件を同時に解く本格的なCADの方式） | 手順型を採用した | — |

## 4. 用語定義

| 用語 | 定義 |
|---|---|
| 手順 | 1つの点を作る操作の記録（使った操作、もとにした点、数値） |
| 基準点 | 最初に置く点。ほかの点に依存しない |
| 距離と方向 | もとにした点から、直前の辺に対して右か左に角度θ曲がり、距離dだけ進んだ点 |
| 直角の折れ点 | 「距離と方向」で、θ＝90°の場合 |
| 二円交点 | 点Aから距離a、点Bから距離bの位置にある点。候補は2つある |
| 許容値 | 二円交点で、2つの円がわずかに届かないとき、接する点として扱う最大の隙間（初期値は3cm） |
| 閉合 | 一周して最初の点に戻り、図形を閉じること |
| 閉合のずれ | 測った寸法で一周したとき、最後の点と最初の点の間に残る距離と向き |
| 部屋 | 既存の点を順に選んで作る、名前の付いた閉じた図形 |
| 依存 | ある点が、別の点をもとに作られている関係 |
| 共通モジュール | ざっくり地積とサクズで共有する部品（リポジトリ sikumi-draw-core【想定】） |
| 座標点 | 取り込んだ座標で位置が決まった点。ほかの点に依存しない（基準点と同じ扱い） |
| SIMA | 測量データの共通形式。座標（A01）と区画（D00〜）を持つ。座標は X＝北、Y＝東、単位m |

## 7. 業務要件

### 7.1 初回価値シナリオ

| 開始状態 | 最初の価値 | 最短経路 | 到達条件 |
|---|---|---|---|
| アプリを開いた直後（図面が0件） | 寸法の入った長方形の駐車場の配置図が、PDFで出る | 新しい図面 → 基準点 → 距離と方向（5.00m）→ 直角の折れ点（右に2.50m）→ 直角の折れ点（右に5.00m）→ 最終点として閉合 → 道路を指定 → 図面の出力 | 図面のプレビューが表示され、PDFに保存できる |

### 7.2 主要リソースのライフサイクル

| リソース | 生成 | 更新 | 削除 | 上限 | 復元 |
|---|---|---|---|---|---|
| 図面 | 新しく作る、複製、作業ファイルの読み込み | いつでも | 確認してから削除する | 端末の容量まで | 書き出した作業ファイルから戻せる。削除した図面は、端末の中では戻せない |
| 手順（点） | 4つの操作で作る | 数値を直すと、依存する点がすべて計算し直される | 確認してから、依存する点もまとめて削除する | 1つの図面あたり200点程度を快適に扱える【想定】 | 元に戻す（50回まで）。アプリを閉じると、元に戻す履歴は消える |
| 部屋・道路・寸法・文字・北の記号 | 既存の点・辺を選んで作る | いつでも | 個別に削除する。もとにした点が削除されたら、一緒に削除する | — | 元に戻す |

### 7.4 主要フローの完結性

| フロー | 失敗・行き止まり | 回復 |
|---|---|---|
| 二円交点 | 隙間が許容値以下 → 接する点として扱い、警告を表示する。許容値を超える → エラー | エラーのときは、その点と、依存する点を「計算できない」と表示する（図には描かない）。数値を直せば、自動で計算し直される |
| 数値の修正 | 修正の結果、後の二円交点が計算できなくなる | 同じく「計算できない」と表示する。元に戻すで戻せる |
| 閉合 | 閉じる辺の長さが測ってあり、計算上の長さと食い違う | ずれ（距離と向き）を表示し、「そのまま閉じる」か「測り直す箇所の目安を見る」かを選んでもらう |
| 中断 | タブを閉じる、通信が切れる | 端末に自動で保存してあるので、次に開いたときに続きから作業できる |

| F-034 | 自由図形: 直線 | 隣地境界・道路の線などを描く | 2点をタップして直線を引く。近くに点があれば吸い付く | 必須（SZ-0.3.0） |
| F-035 | 自由図形: 寸法線 | 任意の位置に矢印付きの寸法を入れる | 2点をタップすると、両端に矢印の付いた寸法線と長さを描く。長さの代わりに任意の文字も入れられる | 必須（SZ-0.3.0） |

| F-037 | 斜線の塗り | 保管場所（車庫）などを示す | 部屋・閉じた図形の設定として、斜線で塗るかを切り替える | 必須（SZ-0.3.0） |
| F-038 | 引き出し線つきの文字 | 指したい場所に説明を付ける | 指す点（または位置）と、文字の位置をタップし、間を引き出し線でつなぐ。点を指した場合は点に追従する。起点だけをあとから動かせる（点の近くに置けば点に付き、矢印の微調整では点から外れる） | 必須（SZ-0.3.0） |
| F-039 | 引照点 | 基準点などを、周りの構造物からの距離で示す | 手順で作った点に「引照点」の印・名前を付け、対象点との間に引照線と距離を表示する。図面に引照点の一覧表を載せるかを切り替えられる | 必須（SZ-0.3.0） |
| F-028 | 三斜法による求積 | 面積の計算過程を表で示す | 閉じた図形を三角形に分け、三斜求積表を作る。計算部分は src/shared に置き、ざっくり地積と共有する | 将来 |

### 8.2 機能詳細

#### 計算ルールの確認表

| ルール・機能ID | 入力の範囲・単位 | 境界 | 不正な入力・競合 | 期待する結果・エラー |
|---|---|---|---|---|
| 距離と方向 F-003 | 距離 d > 0 m（小数第3位まで）。角度 θ は 0°〜180°、右か左 | θ＝0° は直進、θ＝180° は折り返し。最初の辺（直前の辺がない）は、画面の右向きを0°とする | d ≤ 0 や数値でないものはエラー。もとにした点が計算できない場合は、この点も計算できない | 点の座標 |
| 二円交点 F-004 | a・b > 0 m。AとBの距離 D | D＝0（同じ点）→ エラー。gap = max(D−(a+b), \|a−b\|−D) が 0 より大きく許容値以下 → 接する点（警告）。許容値ちょうど → 接する点。許容値を超える → エラー | 候補が2つあるときは、最後に選んでもらう。選んだ側（A→Bの向きに対して左か右か）を記録し、数値を直した後も同じ側を使う | 点の座標、または「計算できない」 |
| 閉合のずれ F-007 | 閉じる辺の、測った長さ（任意） | ずれ = 計算上の長さ − 測った長さ。差が0.5mm未満なら「ずれなし」と表示する【想定】 | 長さを測っていない場合は、ずれを判定しない | ずれの距離と向き |
| 部屋の面積 F-008 | 部屋の頂点（3点以上） | 自己交差していればエラー | 計算できない点を含む部屋は、面積を「—」にする | ㎡、小数第2位を四捨五入【想定】 |
| 許容値 F-016 | 0〜10cm【想定：上限】 | 0 のときは、接する点として扱わない | 範囲外は入力エラー | — |

#### F-004 二円交点
- 計算した直後に、2つの候補を図に表示し、タップでどちらかを選んでもらう。選ぶまで、その手順は確定しない。
- 接する点として扱った場合（隙間が許容値以下）は、手順の一覧にその隙間の量（例: 2.1cm）を表示する。
- 棄却条件: 方針を変えるときに見直す（核の機能）。

#### F-007 閉合
- 入力の途中で「最終点」を指定すると、その点から最初の点へ線を引いて閉じる。
- 閉じる辺の長さが入力されていれば、ずれを表示し、次のどちらかを選んでもらう。
  - **そのまま閉じる**: 図形は計算した点のまま閉じる。図面の閉じる辺には、計算上の長さを表示する。
  - **測り直す箇所の目安を見る**: ずれの向きとほぼ平行な辺を、測り間違いの候補として強調表示する。
- 棄却条件: 方針を変えるときに見直す（核の機能）。

#### F-008 部屋
- 既存の点を順に選んで作る。隣の部屋と、点や辺を共有できる。
- 図面には、部屋の名前と面積を部屋の中に表示し、部屋の一覧表（名前・面積・合計）も載せる。
- 棄却条件: 方針を変えるときに見直す（核の機能）。

#### F-009 道路
- 敷地の辺を1つ以上選び、道路の幅（m）と名前（任意）を入れる。
- 反対側の線を平行に描き、幅の寸法を付ける。線は、選んだ辺より少し長く延ばして描く【想定】。
- 棄却条件: 車庫証明の図面を作らなくなったとき。

#### F-010 寸法
- 自動で付ける対象: 「距離と方向」で入れた距離（線として描かれる辺）。
- 二円交点の距離a・bは、作図用の補助線として表示し、印刷はしない。必要なら、手動で寸法を追加する。
- 表示単位: 図面ごとに「m（小数第2位）」か「mm（整数）」を選ぶ。入力はmで、小数第3位までとする。
- 棄却条件: 方針を変えるときに見直す（核の機能）。

#### F-013 図面の出力
- 用紙: A4縦・A4横（標準）、A3縦・A3横。
- 縮尺: 決まった縮尺の中から、図面が収まる最も大きいものを自動で選ぶ（共通モジュールの仕組み。ざっくり地積のL-07と同じ）。図面に「縮尺 1/N」と書く。
- 表題欄: 題名（例: 保管場所配置図、店舗平面図）、作成日、作成者【想定：項目】。
- 図面にはSIKUMI LABの表示を入れない【想定：ざっくり地積と同じ】。
- 棄却条件: 方針を変えるときに見直す（核の機能）。

#### 作成日の入力（F-013）
- ざっくり地積と同じ標準にする。
  - テキストボックスとカレンダーを併用する。
  - 8桁の数字を入れると、入力中に `yyyy/MM/dd` に整える。
  - 初めてフォーカスしたときは、少し遅らせて全体を選択する。
  - 存在しない日付はエラーにする。
- 初期値は今日の日付（日本時間）。

#### F-029 図面の回転（v0.5 で追加）
- 回転は図面ごとに角度（度）として保存する。点の座標・手順・書き出す作業ファイルの座標は変えない。
- 指定方法: 角度を入れる（−180°〜180°）、または辺を1つ選んで「水平にそろえる」「垂直にそろえる」。
- 画面の表示と印刷の両方に反映する。北の記号・文字・寸法の文字は、読める向き（上下が逆にならない向き）に保つ。
- 回転を0°に戻せば、元の向きに戻る。
- 棄却条件: 回転を一度も使わない状態が半年続くなら、角度入力だけに簡略化する【想定】。

#### F-030 閉じた辺の長さと計算値の表記（v0.5 で追加）
- 「最終点」で閉じた（閉じる辺を測っていない）とき、閉じる辺に寸法を自動で付ける。長さは2点の座標から計算する。
- 直接入力した長さ（距離と方向の距離）以外の寸法は、「（計算値）」を付けて表示する。例: `5.39（計算値）`。対象は、閉じる辺、手動で引いた線の辺、取り込んだ図形の辺。
- 印刷する図面にも同じ表記を載せる。表記の文言はA区分（すぐ変えてよい）。
- 棄却条件: 方針を変えるときに見直す（核の表示ルール）。

#### F-032 閉じた図形の概算面積（v0.6 で追加）
- 対象: 閉じた線すべて（手で作図したもの、取り込んだもの）。部屋（F-008）の面積とは別に表示する。
- 計算: 座標法で計算し、小数第2位に四捨五入して「概算面積 12.75㎡」と表示する。閉合のずれがある場合は、最初の点で閉じた形（「そのまま閉じる」と同じ形）で計算する。
- 表示できないとき: 計算できない点を含む → 「概算面積 —」。線が交差している → 「線が交差しているため計算できません」。
- 表示位置: 図形の中（重心付近）。重なって読みにくい場合は、ドラッグで動かせる【想定】。
- 棄却条件: 方針を変えるときに見直す（核の表示）。

#### F-033〜F-039 周囲の記載と引照点（v0.7 で追加）
- 自由図形（四角・直線・寸法線・文字・引き出し線）は、手順とは切り離して座標（m）で持つ。点の近く（24px以内）をタップすると、その点の位置に吸い付く（吸い付いた後も、点の修正には追従しない）。ただし引き出し線の先端を点にした場合は、その点に追従する。
- 四角は、置いたときの画面の向き（回転を含む）でそろった四角として保存する。大きさ（幅・高さ、m）は数値でも直せる。
- 移動: 「移動」の道具で図形をタップし、移動先をタップする。削除は一覧から行う。
- 寸法線（自由）: 長さは2点間の距離を自動で表示し、「（計算値）」を付ける。任意の文字に置き換えたときは、その文字だけを表示する。
- 縦書き: 文字ごとに「縦書き」を指定できる。
- 斜線の塗り: 部屋・閉じた線ごとに切り替える。画面・印刷の両方に描く。
- 引照点:
  - 対象: 手順で作った点に「引照点」の印を付ける（新しい手順は作らない）。名前（例: 電柱 No.12）と、対象点（1つ以上）を持つ。
  - 表示: ○に十字の記号（仮。あとで変えられる、A区分）、名前、対象点との間の破線の引照線と距離。
  - 距離の表記: その距離が手順で入力した値（二円交点の距離a・b、距離と方向の距離）なら、その値をそのまま表示する。それ以外は「（計算値）」を付ける。
  - 一覧表: 図面に「引照点の一覧（名前・対象点・距離）」を載せるかを切り替える（既定は載せない）。
  - 閉じた図形に含まれない、単独の点でもよい。
- 棄却条件: 車庫証明の図面や引照点の記載を作らなくなったとき（各機能共通）。

#### F-022〜F-027 ファイルの取り込み（v0.4 で追加）

| ルール | 内容 |
|---|---|
| 取り込み先 | 新しい図面として取り込む（既定）か、開いている図面に追加するかを選ぶ |
| 文字コード | UTF-8 として読み、読めなければ Shift_JIS として読む。取り込み画面で手動でも切り替えられる（SIMA・CSVは Shift_JIS のことが多いため） |
| SIMAの座標 | A01 の X（北）・Y（東）を、アプリの y・x に入れ替える。単位はmで、縮尺は指定しない |
| SIMAの区画 | D00〜D99 の区画を、点名の順につないだ閉じた線にする。区画に含まれない点は、座標点だけ取り込む |
| CSVの列と軸 | 取り込み時のプレビューで、点名・X・Y の列、見出し行の有無、軸の向き（測量のX北Y東／数学のx右y上）を選ぶ |
| DXFの対象 | ASCII形式のDXFだけ（バイナリDXFは対象外）。LINE・LWPOLYLINE・POLYLINE・POINT を取り込む。閉じたポリラインは閉じた線にする。同じ座標の点（1mm未満の差）は1つの座標点にまとめる |
| 縮尺（CSV・DXF） | 単位を選ぶ（mm→×0.001、cm→×0.01、m→×1）、または取り込んだ2点を選んで実際の長さLを入れる（倍率 = L ÷ ファイル上の長さ）。倍率は取り込みのときに一度だけ座標に掛けて保存する |
| 点名の重複 | 同じ名前で同じ座標なら1点にまとめる。座標が違えば、別の点として取り込み、名前に「-2」などを付けて警告する |
| 件数 | 点が2,000を超えるときは、動作が遅くなることを知らせ、続けるか確認する |
| 読めないとき | 空のファイル、点が1つもない、形式が違う → 取り込まず、理由（何行目か）を表示する。開いている図面は変えない |
| 面積 | 閉じた図形ごとに座標法で計算し、小数第2位に四捨五入して表示する（部屋と同じ） |

- 棄却条件: 取り込みを使う図面が、半年に1件もないとき（F-023〜F-026）。F-022・F-027 は取り込みの土台なので、取り込み機能と一緒に判断する。

#### 周辺機能の棄却条件
- F-016 設定: 許容値と単位を、一度も既定値から変えない状態が続くなら、設定画面を簡略化する【想定】。
- F-018 共有: 無償で公開しないと決めた場合は不要。

## 17. 受入基準

1. 7.1の初回価値シナリオを、スマホ（Pixel 9a）だけで最後まで行える。
2. 5.00m×2.50mの長方形（7.1の手順）を描き、最初の辺を5.20mに直すと、依存する点が追従する。その結果、図形は台形になり、面積が12.75㎡になる（(5.20+5.00)÷2×2.50）。
3. 3m・4m・5mの二円交点で、直角三角形の頂点が誤差0.1mm以内で求まる。
4. 隙間が2.9cmのとき接する点として扱われて警告が出る。3.1cmのときはエラーになる（許容値3cmの場合）。
5. 二円交点で選んだ側が、数値を直した後も保たれる。
6. 依存のある点を削除すると、確認が出て、依存する点もまとめて削除される。元に戻すで、全部が戻る。
7. 閉じる辺の長さを1cmずらして入力すると、ずれ1cmと、その向きが表示される。
8. 部屋を2つ作ると、面積と合計が一覧表に載り、手計算と一致する。
9. 機内モードで、新しい図面の作成からPDFの出力まで、すべてできる。
10. 外部への通信がないことを、開発者ツールで確認する（C-01）。
11. 作業ファイルを書き出して別の端末で読み込むと、同じ図面になる。知らない版のファイルは拒否される（C-03）。

**MVPに追加した機能の受入基準（v0.5 で追加）**

18. 長方形の図を「長辺を水平にそろえる」で回すと、長辺が水平に表示・印刷される。回した後も、手順の座標の値は変わらない。
19. 3辺だけ測って「最終点」で閉じると、閉じる辺に「（計算値）」付きの寸法が表示され、値が座標から計算した長さと一致する。
20. 2点を選ぶと、その距離が表示され、図面には描かれない。
21. 5.00m×2.50mの長方形を閉じると、図形の中に「概算面積 12.50㎡」と表示される。最初の辺を5.20mに直すと「12.75㎡」に変わる。

**周囲の記載と引照点の受入基準（v0.7 で追加）**

22. 配置図の記載例（自宅の四角・隣地の文字・道路の線・縦書きの「至○○町方面」・斜線の保管場所・寸法線）と同じ内容を、サクズだけで作って印刷できる。
23. 基準点P1から、引照点（電柱）までを二円交点で作ると、引照線の距離に入力した値がそのまま（計算値の表記なしで）表示される。
24. 引き出し線で点を指した文字は、その点の数値を直すと先端が追従する。
25. 引照点の一覧表を載せる設定にすると、名前・対象点・距離が図面に載る。

**取り込み版の受入基準（v0.4 で追加）**

12. 4点の区画を持つ SIMA（Shift_JIS）を取り込むと、点名と座標が一致し、閉じた線と面積が表示される。座標の X・Y が入れ替わっていない（北が上になる）。
13. mm単位の DXF（10000×5000 の長方形）を「mm」で取り込むと、辺長が 10.00m・5.00m、面積が 50.00㎡ になる。
14. 単位の分からない DXF で、長辺を「10m」と指定すると、同じ結果になる。
15. 列の並びが「X,Y,点名」の CSV を、プレビューで列を指定して取り込める。
16. 取り込んだ座標点から、距離と方向・二円交点で作図を続けられる。
17. 壊れたファイルや、点が1つもないファイルは取り込まれず、理由が表示され、開いている図面は変わらない。

## 19. リスクと課題

| リスク | 対応 |
|---|---|
| スマホで点を選び間違える | 選ぶ範囲を広くとり、候補が重なったときは一覧から選べるようにする |
| 測定誤差で、二円交点がたびたび失敗する | 許容値を設定で調整できるようにする |
| 共通モジュールの取り込みが手間になる | 取り込み用のスクリプトと、版の確認をCIに入れる |
| 提出先ごとに図面の様式が違う | 表題欄の項目と、図面のレイアウトはA区分として柔軟に変えられるようにする |
